# kurtain-site

Kurtain의 공개 페이지(개인정보 처리방침). GitHub Pages로 게시한다.
원문은 비공개 저장소 kurtain의 docs/play-submission.md §2.

## app/ — 스토어 안내 페이지

인스타그램 프로필·스토리 링크용: https://hevinxx.github.io/kurtain-site/app/

- Android에서 열면 Google Play로 바로 이동한다. 인스타그램 인앱 브라우저에서는 `market://`로 Play 스토어 앱을 띄운다.
- PC 등 그 밖의 환경에서는 Play 버튼이 있는 안내 페이지가 보인다(`?stay`를 붙이면 휴대폰에서도 이동하지 않는다).
